# Component contracts

Maintainer reference for the **exact behavior** of each text primitive and control. Read the entry for the component you change, and keep it in sync with the code, README, JSDoc, and `docs/`. Not shipped in the package. App-building guidance is in `llms.txt` and `docs/`.

`Text` is a `<p>` (`src/components/text/Text.tsx`). `Heading` is `h1`–`h6` (`src/components/text/Heading.tsx`). `Span` is a `<span>` (`src/components/text/Span.tsx`). `TextLink` is an `<a>` (`src/components/text/TextLink.tsx`). `Button` is a `<button>` (`src/components/buttons/Button.tsx`). `Chip` is a `<span>` badge (`src/components/chips/Chip.tsx`). `Input` is an `<input>` (`src/components/forms/Input.tsx`). `NumberInput` is `<input type="number">` (`src/components/forms/NumberInput.tsx`). `Textarea` is a `<textarea>` (`src/components/forms/Textarea.tsx`). `Select` is a custom listbox (`src/components/forms/selects/Select.tsx`). `MultiSelect` is a custom multi listbox (`src/components/forms/selects/MultiSelect.tsx`). `Switch` is `<input type="checkbox" role="switch">` (`src/components/forms/Switch.tsx`). `Checkbox` is `<input type="checkbox">` (`src/components/forms/Checkbox.tsx`). `Radio` is `<input type="radio">` (`src/components/forms/Radio.tsx`). `Label` is a `<label>` (`src/components/forms/Label.tsx`).

- Color from the nearest `Panel`’s `text` object: omit → `--panelize-text`; `muted` / `highlighted` bools; `color="primary"` / `secondary` / `accent` → `brand.*.base`; `color="danger"` / `warning` / `success` / `info` → `status.*.base` (global, shared schemes). Slot is `{ base, hover, active }`; a hex expands (hover/active derived). Status does not follow `primary`. Raw CSS `color` also wins. If both flags, `highlighted` wins. No `subtle` hex — mix with panel bg (`Chip` tint).
- `Heading`: required `level` `1`–`6` (`headingLevels`). Tag is `h${level}`. Omit `size` → `defaults.heading.size[level]` (`2rem` … `0.67rem`, UA). Instance `size` overrides. Omit `weight` → `bold`. Omit `family` → `display`. Same color / italic / underline / uppercase as `Text`. Margin/padding `0`; `line-height: 1` and `text-box: trim-both cap alphabetic` so the box hugs glyphs (not theme `lineHeight` 1.2). Gap belongs on a layout parent. Publishes `TextStyleContext`. Not a layout shell.
- `Span`: same type props as `Text`. Nested in `Text` / `Span`, omit size/weight/`family` → inherit that line. Omit color → CSS `inherit` (does not reset a parent `color="primary"`). Standalone omit size/weight → `defaults.text`; omit `family` → `base`; omit color still inherit (panel `color` is `text.base`). Also publishes `TextStyleContext` so nested `TextLink` inherits. Not a layout shell.
- `TextLink`: default `defaults.textLink` `color`/`hover` both `primary` (rest `.base`, `:hover` `.hover`, `:active` `.active`). Instance `color='secondary'` / `'accent'` / `'danger'` uses that slot’s hover/active. Nested in `Text` / `Span`, omit size/weight/`family` → inherit. Standalone → `defaults.text` and `family` `base`. `hoverUnderline` default `false` (kept on `:active` when on). `:focus-visible` outline `currentColor`. `hover: 'inherit'` = panel `text.base`. Not a layout shell.
- Library `brand.secondary` / `accent` follow `primary` (same orange until set). Status defaults are `danger` `#f2555a`, `warning` `#ffd60a`, `success` `#4ade80`, `info` `#38bdf8` — they do not follow `primary`. Do not copy a host brand kit into `defaultTheme`. Hosts set the kit in `createPanelizeTheme`.
- Size: `fontSizes`. Weight: omit = `base` 400 (resets inherit); tokens `thin` 100, `base` 400, `bold` 700, `heavy` 800. Open Sans has no 100 (Montserrat does) — host must load the file. Family: `family` token `base` (Open Sans) / `display` (Montserrat) / `mono` (system stack). `Text` / `Button` / `Chip` omit = `base`. `Heading` omit = `display`. The library does not load font files. `lineHeight` is unitless theme `1.2` (not rem). `uppercase` is a bool.
- `Button`: default filled `brand[color]` (theme `defaults.button.color` `primary`) with `ink` (`palette.black`) on the fill. Instance `color='secondary'` / `'accent'` / `'danger'` uses that slot’s `.base` / `.hover` / `.active`. `outline` = transparent fill, slot border + label; hover/active stay hollow on that slot. Filled hover fill is the instance slot’s `.hover`; `defaults.button.hover.color` is the filled label; `hover.background` only if raw CSS (brand/status tokens ignored). `size` = font size; `family` = `fontFamilies` token; `fill` = width/height 100% (height `%` needs a definite parent). Native `disabled` → opacity + `not-allowed`, no hover. Type: `size`, `weight`, `family`, `italic`, `uppercase` (not `muted` / `highlighted` / `underlined`). Instance `padding` / `paddingX` / `paddingY` / `borderWidth` / `borderRadius` override theme (no margin). Instance `background` / `ink` are a token/CSS (all steps) or `{ base, hover, active }`; omitted keys keep the `color` slot / filled ink / transparent `outline`. `background` on `outline` opts in to fill. Outline border stays on `color`. `onClick` is the action (`type='button'` unless set). Caption: `label` (preferred). Custom insides: `children` (layout / `Text` / host icons); `children` win if both set. String `children` allowed, not preferred. Neither allowed; no visible text → `aria-label`. Gap from `defaults.button.gap`.
- `Chip`: badge, not a button. Label is the chroma slot (`.base`) until `ink`. Fill `color-mix(in srgb, chroma ${tint}, var(--panelize-bg))` (`defaults.chip.tint` `12%`) until `background`. Capsule `borderRadius` `999px` until instance. Default `uppercase` `true`, `size` `extraSmall`, `weight` `bold`. Caption: `label`; `children` win. Instance `padding` / `paddingX` / `paddingY` / `borderWidth` (omit `none`) / `borderRadius` / `background` / `ink` / `borderColor` (omit = chroma). `family` is a `fontFamilies` token (omit `base`). No hover. Not a layout shell.
- `Input`: native `<input>` (`type='text'` unless set). Rest fill/ink/border/placeholder from nearest panel (`--panelize-bg` / `text` / `border` / `text-muted`). Instance `color` is **focus chroma only** (border, glow, caret) — not glyph ink (`ink`). Theme `defaults.input.color` `primary`. No offset outline. `:user-invalid` (and `:user-invalid:focus`) uses `status.danger` the same way, including caret. `[aria-invalid='true']` matches for submit-time paint. No `label` (use `Label` / `htmlFor`, or `aria-label`). No `children`. Native `size` omitted (`size` is font). `fill` = width/height 100% like `Button`. `disabled` / `readOnly` → opacity; disabled also `not-allowed`. Instance `borderWidth` / `borderRadius` / `background` / `ink` / `borderColor` override theme / panel rest (`color` stays focus; focus / invalid still own the stroke). Padding chrome like `Button`. Host owns `value` / `onChange` (`ref` is a normal React 19 prop). Shared sheet: `forms/field.ts`. `<Input type='number'>` still works; prefer `NumberInput`. Not a layout shell.
- `NumberInput`: `Input` locked to `type='number'` (`displayName` `NumberInput`). Same chrome (`defaults.input`). Native `min` / `max` / `step` (`'any'` ok). No `type` prop. UA steppers hidden (`appearance: none`); `min` / `max` / `step` are the API. `onChange` value is a string — use `event.currentTarget.valueAsNumber`. Wheel blurs so the value does not nudge. Prefer `Label` + `htmlFor`. Not a layout shell.
- `Textarea`: copy of `Input` as `<textarea>`. Shared field chrome. `createPanelizeTheme` starts `defaults.textarea` from the **merged** `defaults.input`, then applies `resize` / `rows` and `defaults.textarea` overrides. Default `resize` `false`, `rows` `3`. Instance `resize` opts in (CSS `vertical`); `fill` does not turn it off. Native `rows` overrides theme. Horizontal / both via `css`. Not a layout shell.
- `MultiSelect`: custom multi listbox (`displayName` `MultiSelect`), not `multiple` on `Select`. Same trigger chrome / portal / `defaults.select` as `Select` (shared `selects/listbox.ts` / `selects/listboxChrome.ts`). Host `value` / `onChange(value: string[])` (empty array when cleared). Trigger shows a **count** (`N selected`) — no chips, no wrap. Menu stays open while toggling. Rows are library `Checkbox` + label; checked rows use chroma ink (same as selected `Select`) plus the filled check; hover fill only. `clearable` is clear-all ×. `required` blocks empty (cannot uncheck the last). `selectedAtTop` lists checked rows first; highlight stays on the same `value` after reorder. `readOnly` inspects without toggle / clear (not dimmed; row `Checkbox` is not `disabled` for inspect). No `emptyOption`. `name` → one hidden input per value (empty → `value=''` + `required`). Pointer clear / caret-close / outside **blur**; toggle / Escape keep focus; Tab away closes. Keyboard: arrows, Enter / Space toggle, Escape on the trigger (not `window`), Home, End, type-ahead; Backspace / Delete clears when clearable; skip disabled. Closed type-ahead **opens and highlights** (does not toggle). `aria-autocomplete='none'`. Listbox `aria-labelledby` only when `id` is set. Prefer `Label` + `htmlFor`. `fill` stretches the trigger. Not a layout shell.
- `Select`: custom listbox, not a native `<select>` (`displayName` `Select`). Trigger is a `button` with `fieldChromeCss` (same rest / focus / `aria-invalid` as `Input`). Menu `createPortal`s to `document.body`, `position: fixed` from the trigger rect (flips above if needed). `createPanelizeTheme` starts `defaults.select` from the **merged** `defaults.input`, then `listMaxHeight` / `listOffset` / `optionPaddingX` / `optionPaddingY` / `listZIndex` / `listShadow` and `defaults.select` overrides. Host `value` / `onChange(value: string)` (empty string when cleared; unknown `value` still shows). Omit `open` = internal; pass `open` + `onOpenChange` to control. `options` array and/or child `Option` (children win on duplicate `value`). `placeholder` when empty (**muted** ink). `required` blocks empty and sets the hidden input `required`. `clearable` shows a muted × (22px hit, smaller hover circle fill; ignored when `required`). `selectedAtTop` lists the selected option first (`emptyOption` row stays first). `emptyOption` (`true` or a caption string) prepends a `''` row (`true` → `placeholder`; ignored when `required`). `readOnly` opens to inspect, no pick / clear (not dimmed; `aria-readonly`). Without `required`, click selected to deselect. `name` → hidden input (`disabled` with the select). Pointer pick / clear / caret-close / outside click **blur**; keyboard pick / Escape keep focus; Tab away closes. Keyboard: arrows, Enter, Space, Escape on the trigger (not `window`), Home, End, type-ahead; Backspace / Delete clears when clearable; skip disabled. `aria-autocomplete='none'`. Listbox `aria-labelledby` only when `id` is set. Open highlights the selected (else first enabled) row. CSS chevron is muted (`inset-inline-end` with the ×). Rest option labels and the **value** use panel `text.highlighted` until `ink`. Selected option: chroma label + CSS check, no fill. Hover/keyboard active: gray mix fill only — label color does not change. No native fallback / multi / combobox field / optgroups. Instance `color` is focus chroma (open ring, selected label, check), not rest trigger / option glyph (`ink`). Native `size` omitted (`size` is font). `fill` stretches the trigger. Prefer `Label` + `htmlFor`. Not a layout shell.
- `Switch`: native `<input type='checkbox'>` with `role='switch'` (`displayName` `Switch`). On track is `color` chroma (theme `defaults.switch.color` `primary`) — `.base` / `.hover` / `.active` when checked (same steps as `Button`). Off track mixes `--panelize-text` into `--panelize-bg` until `background` (28% mix and thumb shadow are hardcoded, not theme keys). Thumb is `defaults.switch.ink` (`palette.white`) until `ink`. Track height is type `size` × theme `lineHeight` (keep `lineHeight` unitless). Width is type × `defaults.switch.widthFactor` (default `2`). Inset is type × `insetFactor` (default `0.2`); thumb is height − 2×inset. Capsule `borderRadius` (`999px`) until instance. Thumb uses `min(radius, 50%)`. Instance `size` is a `fontSizes` token (or CSS). Same `size` on the paired `Label`. Instance `width` / `height` are space tokens or CSS (not `fontSizes`) and override the track axes. Instance `borderRadius` is a radii token or CSS. Instance `color='secondary'` / `'accent'` / `'danger'` uses that slot on the on track. No `type` / `fill` / `label` / `children`. Native `size` omitted. Native `checked` / `defaultChecked` / `disabled` / `onChange`. `:focus-visible` glow uses on-track chroma. Prefer wrapping `Label` + `htmlFor`. Not a layout shell.
- `Checkbox`: native `<input type='checkbox'>` (`displayName` `Checkbox`). `color` is the chroma slot (theme `defaults.checkbox.color` `primary`) — `primary` / `secondary` / `accent` / status. Empty rest / hover / active stroke is `currentColor` (wrapping `Label`, else panel `text.base`) until `borderColor`. Checked / indeterminate fill the `color` slot’s `.base` / `.hover` / `.active`. Rest fill is transparent until `background`. `borderWidth` default `extraSmall` (`1px`). Check / dash is `defaults.checkbox.ink` (`palette.black`, same as filled `Button`) until `ink` (`PaintSteps`; hover/active unused on the mark). Box is type `size` (`1em`), square. Same `size` on the paired `Label`. `borderRadius` default `small`. Instance `size` is a `fontSizes` token (or CSS). Instance `width` / `height` override the box axes. `indeterminate` sets the native property (dash), not `checked`. `hideCheckIcon` (default `false`) is fill-only when checked (no check glyph); the dash still draws when indeterminate. No `type` / `fill` / `label` / `children`. Native `size` omitted. Native `checked` / `defaultChecked` / `disabled` / `onChange`. Empty `disabled` keeps inherited stroke (muted wrapping `Label`); checked / indeterminate dim like `Button`. Disabled skips hover. `:focus-visible` glow uses on-fill chroma. Prefer wrapping `Label` + `htmlFor`. Not a layout shell.
- `Radio`: native `<input type='radio'>` (`displayName` `Radio`). `color` is the chroma slot (theme `defaults.radio.color` `primary`) — `primary` / `secondary` / `accent` / status. Empty rest / hover / active stroke is `currentColor` (wrapping `Label`, else panel `text.base`) until `borderColor`. Checked ring and inner disc fill the `color` slot’s `.base` / `.hover` / `.active`. Rest fill is transparent until `background` (panel shows in the gap around the disc). `ink` is the disc (`PaintSteps`, same as `Checkbox`); omit = disc follows `color` including hover/active. `borderWidth` default `extraSmall` (`1px`). Box is type `size` (`1em`), circle. Same `size` on the paired `Label`. `borderRadius` default `999px`; inner disc uses `min(radius, 50%)`. Disc inset is type × `insetFactor` (default `0.22`). Instance `size` is a `fontSizes` token (or CSS). Instance `width` / `height` override the box axes. No `type` / `fill` / `label` / `children`. Native `size` omitted. Native `name` / `value` / `checked` / `defaultChecked` / `disabled` / `onChange`. Empty `disabled` keeps inherited stroke (muted wrapping `Label`); checked dims like `Button`. Disabled skips hover. `:focus-visible` glow uses on-ring chroma. Prefer wrapping `Label` + `htmlFor`. Not a layout shell.
- `Label`: `<label>`. Glyph ink like `Text` (`defaults.text`) — `color` / `muted` / `highlighted`. `line-height: 1` and `text-box: trim-both cap alphabetic` (same idea as `Heading`) so the box hugs glyphs. Unset `text-box` when the label wraps a control so the control is not clipped. Field glyphs are `ink`; field `color` is focus. Caption: `label` (preferred); `children` win if both are set. `htmlFor` points at the control `id`. Cursor is `pointer` for `htmlFor` / `onClick` / a wrapped control; `not-allowed` only when the label **wraps** a `:disabled` control (`:has`). Sibling-only `htmlFor` cannot see `disabled`. Field labels stay `pointer`; the field keeps `text` / `not-allowed`. Wrap `Switch` / `Checkbox` / `Radio` (and use the same `size`) rather than a sibling caption. Not a layout shell.
- Not a layout shell: no `fill` / `flex` / padding on `Text` / `Heading` / `Span` / `TextLink` / `Label`. `Chip` / `Input` / `NumberInput` / `Textarea` / `Select` / `MultiSelect` padding is chrome (like `Button`), not a layout box. `Button` / `Input` / `NumberInput` / `Textarea` / `Select` / `MultiSelect` / `Switch` / `Checkbox` / `Radio` are controls (`fill` on fields/buttons/select stretches the control, not a panel; `Switch` / `Checkbox` / `Radio` have no `fill`).
- Same docs checklist as layout when the public type API changes.
